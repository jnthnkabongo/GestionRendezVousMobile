MY2K MINING S.A.R.L — Pack de logos
======================================

Contenu :
- logo_web_*.png : logos horizontaux pour en-têtes web et mobile.
- logo_app_*x*.png : versions carrées pour icônes d'application.
- planche_formats_originale.png : planche récapitulative générée.

Les PNG sont en RGBA avec fond transparent lorsque possible.
Note : les petites tailles peuvent perdre des détails. Pour un logo officiel parfaitement fidèle,
il est préférable de fournir un fichier source vectoriel (SVG/PDF) ou une image haute résolution.
